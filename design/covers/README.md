# Book covers

The eight covers for The Other Room's bookshelf, as one system.
`cover.html` draws them (shared layout + one art function per book); `render.py` renders 1200 × 1800 PNGs with Playwright.
The fonts are read from `../../fonts` (copy the woff2 files next to `cover.html` before rendering).
Web versions live in `img/books/<key>-400.webp` and `-800.webp`. Full-size JPGs are kept here.
